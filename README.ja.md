# nafi

[English](README.md)

nafiは、macOS 14以降に対応するネイティブなマルチペインファイルマネージャーです。SwiftUIとAppKitで構成し、ブラウザのタブにはmacOSの実際のウインドウタブを使います。ローカルフォルダと対応するリモート接続先を、同じペインとファイル操作で扱えます。rclone常駐ランタイム、同期センター、増分同期、File Provider拡張、Drop Stack、Quick Open、名前付きワークスペース、ログイン項目・シェル連携を含みます。

## 必要な環境

- macOS 14以降
- ビルドにはXcode 16以降とXcodeのコマンドラインツール
- ローカルビルドでアプリアイコンを生成する場合は、Homebrewの`librsvg`。`rsvg-convert`がなくてもビルドは続行しますが、アイコンは生成されません

## ビルド

アプリケーションバンドルを作成します。

```bash
./scripts/build-app.sh
```

このスクリプトはリリースビルドを実行し、`.build/nafi.app`を作成します。利用可能なローカル開発用署名を使って署名し、見つからない場合はアドホック署名を使ってから、バンドルを検証します。インストール済みアプリのFile Provider拡張と競合しないように、通常は開発用バンドルをLaunch Servicesへ登録しません。開発用バンドルを登録する場合は`NAFI_REGISTER_BUILD=true`を、Finderで表示する場合は`NAFI_REVEAL_BUILD=true`を指定してください。

SwiftPMのビルドディレクトリを削除して再ビルドする場合:

```bash
rm -rf .build
./scripts/build-app.sh
```

GitHub Actionsは`macos-15`でビルドし、利用可能ならXcode 16.4を選択します。`v*.*.*`形式のバージョンタグでは、ZIPとDMGを成果物として公開します。

## 機能

### ワークスペース

- 起動時は1ペインです。必要なときだけ分割できます。
- 左右または上下へ再帰的に分割でき、分割線をドラッグして幅や高さを調整できます。
- ブラウザのタブにはmacOSの標準タブバーを使います。Command-T、追加ボタン、選択、並べ替え、切り離し、閉じる操作に対応します。
- macOSの各ウインドウタブが独立したワークスペースを持ち、各分割ペインが1つのファイルモデルを持ちます。
- マウスダウン時の選択、右クリック時の対象選択、Commandによる追加・解除、Shiftによる範囲選択、Command-Shiftによる範囲追加、すべて選択、キーボード操作、Escape、Finder風のドラッグ範囲選択に対応します。
- ファイルのドラッグは移動が既定です。Optionを押しながらドロップするとコピーします。
- ローカルまたはリモートのファイル操作後に、影響を受けるタブとペインを更新します。

### 閲覧と編集

- リスト、マトリクス、カラム、ギャラリーの4種類の表示に対応します。
- 履歴移動、親フォルダへの移動、パスの直接入力、マウント済みボリュームの閲覧、横スワイプによる戻る・進むに対応します。
- 現在のフォルダ、その配下、ローカルボリュームまたはリモートサーバー全体を検索できます。
- フォルダのみ、コンテンツの種類、拡張子グループで検索結果を絞り込めます。再帰検索の結果は最大5,000件です。
- 名前、更新日、サイズ、種類で並べ替えられます。隠しファイルの表示と、マトリクス表示のアイコンサイズも設定できます。
- Quick Look、ネイティブファイルアイコン、パッケージ、Finderタグ、POSIX権限、ファイル情報に対応します。
- 対応するテキスト・ソースファイルを最大8 MiBまでクイックエディットできます。判定した文字コード、BOM、改行コードを維持し、保存前に外部変更を確認します。
- iCloud Driveの未ダウンロード項目をクイックエディットするときは、macOSへダウンロードを要求します。

### ファイル操作

- ファイルとフォルダの作成、名前変更、一括名称変更、複製、Finderエイリアスの作成、選択項目のZIP圧縮、安全なZIP展開、ローカル項目のゴミ箱への移動に対応します。
- 通常のアプリケーションで開くほか、アプリケーションを選んで開く操作、情報を見る画面からの標準アプリ変更に対応します。
- コピー、カット、ペースト、ドラッグ・アンド・ドロップ、同名項目の処理、パスのコピー、Finderで表示、ここでターミナルを開く操作に対応します。
- ローカルと対応するリモートルートで同じ操作と衝突処理を使います。コピーと移動のジョブは永続化され、設定画面から一時停止、再開、キャンセル、再試行できます。置き換え前にトランザクション用一時名へ転送し、サイズまたはSHA-256で検証します。直接名前変更できない異なるルート間の転送は、非公開の一時領域を経由します。
- 対応するS3操作ではサーバー側コピーを使い、128 MiB以上のローカルファイルをS3へアップロードするときはマルチパートアップロードを使います。

### サーバーとクラウドストレージ

| 接続先 | 接続実装 | ペインでの扱い |
| --- | --- | --- |
| SMB、WebDAV、NFS、AFP | macOS NetFS | マウント済みのローカルファイルURL |
| SFTP（パスワードまたは秘密鍵） | macOS OpenSSH（`/usr/bin/sftp`） | 内部の`nafi-remote://` URL |
| FTP、明示的FTPS、暗黙的FTPS | アプリ内のSwiftNIOクライアント | 内部の`nafi-remote://` URL |
| S3互換ストレージ | AWS Signature V4対応のURLSession | 内部の`nafi-remote://` URL |

S3互換接続では、AWS S3、Cloudflare R2、MinIO、Ceph、匿名の公開バケット、独自HTTPSエンドポイント、仮想ホスト形式またはパス形式、プレフィックス、一時セッショントークン、サーバー側コピー、マルチパートアップロードを利用できます。Cloudflare R2ではアカウントエンドポイントと`auto`リージョンを使います。

SMB、WebDAV、NFS、AFPの接続でFinderや他のGUIクライアントは起動しません。SFTP、FTP、FTPS、S3互換ストレージでもmacFUSE、`sshfs`、Cyberduckなどの外部ブラウザは必要ありません。ローカルとリモートのルートを、macOSのタブと分割ペインに混在させ、Favoritesに保存できます。

接続に関する補足:

- 起動時の自動接続を有効にしたプロファイルは、バックオフを挟んで最大3回再試行します。
- FTP、`AUTH TLS`を使う明示的FTPS、暗黙的FTPSに対応します。FTPSではTLS 1.2以降を使い、証明書検証は既定で有効です。
- SFTPは両方の認証方式でmacOSのOpenSSHを使い、`StrictHostKeyChecking=yes`を指定します。初回接続前に設定画面でサーバー鍵の指紋を取得・表示して明示的に承認し、信頼した鍵を`~/Library/Application Support/nafi/known_hosts`へ保存します。未登録または変更された鍵は拒否します。
- 「ここでターミナルを開く」はローカルフォルダとSFTPルートで利用できます。FTPとFTPSには対話的なシェルがありません。
- パスワード、SFTP秘密鍵のパスフレーズ、S3シークレットキー、一時S3セッショントークンはmacOS Keychainに分けて保存します。秘密鍵ファイルの内容は選択した場所に残し、接続時だけ読み込みます。

### macOSとの統合

- フォルダ、ディレクトリ、ボリューム、マウントポイント、一般的なファイル形式をLaunch Servicesへ登録します。
- 設定画面から、フォルダ、ボリューム、マウントポイントをnafiで開く標準アプリへの変更と、Finderへの復元を要求できます。
- Finder、Services、他のアプリケーション、Launch Servicesから受け取ったフォルダやファイルを、現在のタブまたは新しいタブで開きます。ファイルは含まれているフォルダを開いて選択します。
- 選択したファイルやフォルダをnafiで開くFinder Servicesを提供します。
- iCloud Driveを自動検出し、ユーザーが場所を選んだ場合はセキュリティスコープ付きブックマークを保存します。

## データとプライバシー

アプリケーションの状態は`~/Library/Application Support/nafi`に保存します。

- `servers.json`にはサーバープロファイルを保存します。秘密情報は含めません。
- `sidebar.json`にはサイドバーの構成を保存します。
- `icloud-drive.bookmark`には、手動で選択したiCloud Driveのセキュリティスコープ付きブックマークを保存します。
- `known_hosts`には、明示的に信頼したSFTPホストキーを保存します。
- `transfers.json`には、件数とサイズに上限を設けた永続転送キューと直近の完了履歴を保存します。

nafiは閲覧したフォルダへ独自の表示メタデータを書き込まず、`.DS_Store`を作成しません。Finderや他のアプリケーションが作成するメタデータは抑止しません。リモート項目のQuick Look、サムネイル、編集、ルート間転送では、操作中に一時的なローカルファイルを作成する場合があります。
